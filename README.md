# Scuffy.sh — Portafolio ML + Hacking

Sitio web personal que recoge proyectos de Machine Learning / Deep Learning, proyectos de hardware / embedded y WriteUps detallados de máquinas CTF de hacking ético.

Construido con [Jekyll][jekyll] + [Minimal Mistakes][mm] y hosteado en GitHub Pages.

## Secciones

- **Proyectos** — Implementaciones de modelos de aprendizaje supervisado y profundo aplicados a problemas reales, con análisis, evaluación y resultados, junto con proyectos de hardware / embedded.
- **Writeups - Hacking Ético** — WriteUps detallados de máquinas CTF, documentando el proceso de enumeración, explotación y escalada de privilegios.

[jekyll]: https://jekyllrb.com
[mm]: https://mademistakes.com/work/minimal-mistakes-jekyll-theme/
